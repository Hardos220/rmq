# Безопасность / Security

## Как сообщить об уязвимости

Не открывайте публичный issue. Сообщите приватно: вкладка **Security** этого репозитория → **Report a
vulnerability** (GitHub Private Vulnerability Reporting). Опишите, что можно сделать, как это воспроизвести и на
какой версии (`rmq --version`). Ответ — как только смогу; исправление выйдет обычным релизом, и установленные
менеджеры обновятся сами.

Please do not open a public issue. Report privately: the **Security** tab of this repository → **Report a
vulnerability**. Include what can be done, how to reproduce it and the version (`rmq --version`).

## Поддерживаемые версии

Только последний [релиз](https://github.com/Hardos220/rmq/releases/latest): установки из архива обновляются до него
сами.

## Что считается уязвимостью

- доступ к дашборду или API менеджера не с этого ПК, или действия владельца (настройки, режимы, выключение, чужие
  задачи) без его токена;
- запросы к сетевому порту менеджера, которые проходят без подписи ключом сети, повторяются или выходят за права
  участника (например, участник сети с друзьями управляет «Моими ПК» владельца);
- задача участника сети, которая меняет файлы владельца, видит его переменные окружения или выходит за свою папку;
- обновление, которое можно подменить (менеджер ставит только релизы этого репозитория и сверяет SHA-256);
- утечка токена дашборда или ключа сети.

Как устроена защита — разделы «Безопасность и приватность» и «Вычислительная сеть» в [README](README.md).
