## Как устроен проект

Менеджер написан на Python 3.10+ и работает только в Windows. Из сторонних пакетов — только
[psutil](https://github.com/giampaolo/psutil); всё остальное — стандартная библиотека и Windows API через `ctypes`.

| Файл | Что в нём |
|---|---|
| `rmq/planner.py` | правила планировщика: кто стартует, кого ужать или заморозить. Чистая логика без ввода-вывода, покрыта тестами |
| `rmq/manager.py` | цикл менеджера: замеры, план, действия, статистика, состояние для дашборда |
| `rmq/jobs.py`, `rmq/wrapper.py` | процессы задач: Job Objects, приоритеты, заморозка |
| `rmq/monitor.py`, `rmq/games.py` | счётчики Windows (CPU, память, видеокарта), определение игр |
| `rmq/thermal.py` | датчики температуры, мощности и частот, регулятор, правило перегрева |
| `rmq/metrics.py`, `rmq/stats.py` | история графиков в памяти; статистика в CSV (`data\stats`) |
| `rmq/forecast.py` | прогноз очереди и скорость других ПК |
| `rmq/chronicle.py`, `rmq/swing.py`, `rmq/progress.py` | «Хроника», колебания нагрузки, прогресс задач |
| `rmq/server.py`, `rmq/static/` | HTTP API и дашборд (обычные HTML, CSS и JavaScript без сборки) |
| `rmq/cli.py` | команда `rmq` |
| `rmq/net.py`, `rmq/netbase.py`, `rmq/linkcheck.py`, `rmq/firewall.py` | вычислительная сеть через Tailscale и диагностика связи |
| `rmq/updater.py`, `rmq/update_apply.py` | автоматические обновления из релизов |
| `rmq/install.py` | ярлык и правила для агентов |
| `rmq/settings.py`, `rmq/db.py`, `rmq/texts.py`, `rmq/winapi.py`, `rmq/util.py` | настройки, база SQLite, тексты, Windows API, мелочи |
| `AGENTS.md`, `agent_rules.md` | полное руководство для агентов (`rmq guide`) и короткий блок для их инструкций |
| `tools/` | установщик датчика температуры процессора, сквозной тест, сборка релиза |

## Разработка

```bat
git clone https://github.com/Hardos220/rmq.git
cd rmq
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt pytest
start.cmd
```

`start.cmd` запускает менеджер с окном логов, дашборд — http://127.0.0.1:8777. Рабочая копия (папка с `.git`)
не обновляет себя из релизов.

Если на этом же ПК уже работает установленный менеджер, запускайте рабочую копию на другом порту (в
`data\settings.json`: `{"server": {"port": 8795}}`) и с переменной `RMQ_URL=http://127.0.0.1:8795`. Команды
`install-agents` и обновления меняют правила агентов в вашем профиле: для опытов подставляйте временный
`USERPROFILE`.

## Тесты

```bat
python -m pytest tests -q          :: правила, статистика, сеть, прогноз — секунды
python tools\e2e_home.py           :: сквозная проверка, ~3 минуты
```

`tools\e2e_home.py` поднимает два временных менеджера (порты 8790 и 8791, сеть — на 127.0.0.1:8781 и 8782),
объединяет их в «Мои ПК», гоняет задачи между ними и открывает дашборд в Microsoft Edge без окна: страницы должны
загрузиться без ошибок в консоли. Снимки страниц остаются в `%TEMP%\rmq-e2e-shots` — посмотрите их: проверка консоли
не ловит ошибки вёрстки.

## Правила проекта

- **Владелец ПК всегда первый.** Менеджер не ограничивает процессы пользователя ни при каких условиях (даже при
  перегреве), не требует прав администратора, не ставит служб и драйверов, не меняет системные настройки.
- **Без новых зависимостей без нужды.** Сейчас это только psutil; дашборд — без фреймворков и сборки.
- **Интерфейс и руководство для агентов — на русском**, комментарии в коде — на английском.
- **Документация вместе с кодом.** Поменялось поведение — обновите `README.md`, а если это видят агенты — `AGENTS.md`
  (его читают агенты: `rmq guide`) и при необходимости `agent_rules.md`. Новые колонки статистики описываются в
  тексте `README` внутри `rmq/stats.py`.
- **Пулл-реквест:** что и зачем меняется, тесты проходят; для изменений дашборда — снимок экрана, для сети —
  прогон `tools\e2e_home.py`.

## Выпуск версии (только владелец репозитория)

Установленные менеджеры обновляются сами из релизов этого репозитория, поэтому выпускает их только владелец.

```bat
:: 1. поднять __version__ в rmq\__init__.py, проверить и закоммитить
python -m pytest tests -q
python tools\e2e_home.py
git commit -am "…" && git push
:: 2. собрать архив (в него входят сторонние программы из tools\, которых нет в git) и опубликовать релиз
python tools\make_release.py
gh release create vX.Y.Z dist\rmq-X.Y.Z.zip dist\SHA256SUMS.txt --title "RMQ X.Y.Z" --notes "что нового"
```

Через несколько часов все установки обновятся сами. Те же заметки добавьте в начало [CHANGELOG.md](CHANGELOG.md).
