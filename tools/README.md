# Датчик температуры процессора (офлайн)

Windows не отдаёт температуру кристалла процессора без драйвера. Здесь лежит всё, чтобы её получить
без интернета:

| Файл | Что это |
|---|---|
| `PawnIO_setup.exe` | драйвер PawnIO 2.2.0 (подписан автором, namazso.eu): через него программы мониторинга читают датчики процессора |
| `LibreHardwareMonitor.zip` | LibreHardwareMonitor 0.9.6 (открытый исходный код) — читает датчики через PawnIO |
| `SHA256SUMS.txt` | контрольные суммы, совпадающие с опубликованными на GitHub |
| `install_cpu_sensors.ps1` | установка (нужен один запрос UAC) |
| `uninstall_cpu_sensors.ps1` | удаление всего, что поставила установка |

Как это устроено:

- **Где стоит LibreHardwareMonitor.** В `C:\Program Files\LibreHardwareMonitor`. Он запускается при входе в Windows
  с правами администратора, свёрнутым в трей.
- **Что он опрашивает.** Только процессор. Видеокарту, диски и контроллер платы он не трогает: видеокарту и SSD
  менеджер читает сам, не будя спящую видеокарту.
- **Как менеджер получает температуру.** Через локальный веб-сервер LHM на порту 8085, с паролем. Входящие
  соединения из сети блокирует брандмауэр Windows. Сам менеджер работает без прав администратора и берёт
  пароль из файла настроек LHM.
- **Интернет не нужен.** Ни LibreHardwareMonitor, ни PawnIO в интернет не обращаются.

Переустановка или удаление — из PowerShell с правами администратора:

```powershell
powershell -ExecutionPolicy Bypass -File <папка менеджера>\tools\install_cpu_sensors.ps1
powershell -ExecutionPolicy Bypass -File <папка менеджера>\tools\uninstall_cpu_sensors.ps1
```
